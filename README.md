## 🚀 Sobre o projeto

Tela de login desenvolvida com **HTML, CSS e JavaScript**, focada em praticar estruturação de formulários e estilização responsiva.

O objetivo é oferecer uma interface simples e funcional, que pode ser usada como base para projetos maiores que necessitem de autenticação.

👉 [Acesse a página no GitHub Pages](https://lepofernandes.github.io/Projeto-Login/)
👉 [Repositório no GitHub](https://github.com/LepoFernandes/Projeto-Login)

## 🛠 Tecnologias

* HTML5
* CSS3


## ⚙️ Como rodar localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/LepoFernandes/Projeto-Login.git
   ```
2. Acesse a pasta do projeto:

   ```bash
   cd Projeto-Login
   ```
3. Abra o arquivo `index.html` no navegador.

## 📌 Aprendizados

Durante esse projeto, pratiquei:

* Estruturação de formulários HTML
* Estilização de inputs e botões com CSS
* Layout responsivo para diferentes tamanhos de tela
